## 🛠️ Our Tech Manifesto

We value speed, autonomy, and clean engineering. Our experimental builds enforce strict architectural constraints:

* **Fast Tooling First:** We build and manage with high-performance toolchains (`uv` for Python, `bun` for JS/TS/Runtime, `mise` for polyglot version management).
* **Containerized Environments:** If it can't run in a deterministic `Docker` stack, it doesn't belong in production.
* **Strict Typing & Schemas:** Rigorous data modeling via Pydantic, TypeScript, or strict SQL/NoSQL schemas. No loose data allowed.
* **Event-Driven & Modular:** Every tool we ship must be decoupled, easy to mirror, and ready to be integrated into broader workflows.

## 📁 Repository Archetypes

Our ecosystem is structured around three core pillars:

* `*-core` / `*-cli` : Production-grade tools, packages, and command-line interfaces.
* `*-infra` / `*-ops` : Orchestration scripts, Docker compose ecosystems, and deployment blueprints.
* `sandbox-*` : Raw, unstructured research, tool benchmarks, and technical proof-of-concepts.
