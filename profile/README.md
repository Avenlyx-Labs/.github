### 🔮 Welcome to the Forge

**Avenlyx Labs** is an independent R&D playground and software factory. We analyze, benchmark, and break every modern tech tool on the market to build high-performance utilities, automated systems, and production-ready architectures.

> [!NOTE]
> We don't stick to one stack. We test everything, eliminate the noise, and ship the signal.

---

## ⚡ What We Do

* 📊 **Toolchain Benchmarking:** Evaluating frameworks, LLMs, databases, and deployment pipelines under heavy constraints.
* 🤖 **Automation & Scrapers:** Building advanced, resilient data collection, browser automation, and workflow orchestration systems.
* 🔀 **Polyglot Architecture:** Designing specialized services where SQL, NoSQL, and local AI vector spaces co-exist seamlessly.
* 💻 **Developer Experience (DX):** Creating minimalist, lightning-fast CLI tools and automated developer environments.

---

## 🛠️ Our Tech Manifesto

We value speed, autonomy, and clean engineering. Our experimental builds enforce strict architectural constraints:

| Layer | Stack Focus | Core Philosophy |
| :--- | :--- | :--- |
| **Fast Tooling** | `uv` • `bun` • `mise` | Zero execution overhead, instant bootstraps. |
| **Infrastructure** | `Docker` • `Tailscale` | If it's not deterministic and isolated, it's broken. |
| **Data Integrity** | `Pydantic` • `TypeScript` | Strict typing and schema enforcement. No loose JSONs. |
| **Design Pattern** | `Event-Driven` • `Modular` | Decoupled systems ready to be plugged into wider pipelines. |

---

## 📁 Repository Archetypes

To keep our chaos organized, every repository follows a strict naming convention:

* 🟩 `*-core` / `*-cli` : Production-grade tools, standalone packages, and command-line interfaces.
* 🟦 `*-infra` / `*-ops` : Orchestration scripts, network tunnels, Docker compose ecosystems, and deployment blueprints.
* 🟨 `sandbox-*` : Raw, unstructured research, tool benchmarks, and technical proof-of-concepts.

---

## 🤝 Collaboration & Standards

We enforce strict Git hygiene and clean development patterns across all repositories:

* 🟥 **Semantic Commits:** Following standard specifications (`feat:`, `fix:`, `docs:`, `refactor:`, `chore:`).
* 🗑️ **Zero Technical Debt:** Unused dependencies or legacy configurations are purged instantly. No lingering draft files.
